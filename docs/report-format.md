# Risk Assessment Report Format

## Structure (matches existing MEX reports)

1. **Cover page** — Client, site, "Risk Assessment", version, MEX branding/footer
2. **Documentation reference** — Project name/number, author, reviewer, version history table, team members table
3. **Contents** — Auto-generated TOC
4. **Project background and target** — Scope, focus areas (access points, energies, control groups, existing safety systems, drawings), site overview photo, statement linking to next safety upgrade stage
5. **Introduction of risk assessment**
   - 5.1 Steps (AS4024.1201 flowchart — embedded as image)
   - 5.2 Limits of machinery (use, space, time, other)
   - 5.3 Methodology (inductive method — bottom-up preliminary hazard analysis)
   - 5.4 HRN parameter tables (LO, FE, DPH, NP) + risk banding table with colour coding
6. **Limits of the report** — Data collection date/methods, liability disclaimer, hazard evaluation caveats, lifecycle exclusions
7. **Risk analysis** — Hazard-by-hazard entries, each containing:
   - Section heading with location/asset reference
   - Photo(s) — annotated where applicable
   - HRN table: Mode | Task | Hazard | LO | FE | DPH | NP | HRN (colour-coded)
   - Risk Reduction row with New Risk Estimation
   - Explanation with parameter justifications and standards references
8. **Safety function** — PLr determination per machine/group:
   - ISO 13849-1 risk graph (S/F/P → PLr) embedded as image
   - Parameter selection with justification
   - Specific safety function analysis (e.g., drive STO, safety controller wiring)
9. **Conclusion** — AI-synthesised: systemic issues, overall PLr/Category recommendation, link to next stage proposal

## Formatting Rules
- MEX logo top-right of every page
- MEX footer on every page (phone, address, email, license, ABN, website)
- Page numbers centred
- HRN score cells colour-coded per risk band
- Risk reduction rows use light green background
- Tables use consistent column widths across all hazard entries
- Photos full-width or half-width depending on content
