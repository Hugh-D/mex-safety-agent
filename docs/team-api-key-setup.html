API Key Setup Guide

MEX Safety Platform — Team Onboarding · May 2026

Each team member gets a personal API key that authenticates your device with the MEX Safety Platform API. This takes under two minutes. Follow the steps for your platform below, then confirm with Buzzy that your key appears in the table.
🖥 Web App

Desktop (Browser)

apps/web/.env.local

1

Open the project folder and navigate to apps/web/

2

Create a new file called .env.local (note the dot)

3
Paste exactly this — replace with your key
VITE_API_KEY=mex-yourname-2026
4

Save and restart the dev server (npm run dev)

📱 Mobile App

Mobile (Expo)

apps/mobile/.env

1

Open the project folder and navigate to apps/mobile/

2

Open the existing file .env (already exists — do not create a new one)

3
Find this line and replace the placeholder key
# Replace the placeholder with your key from the table below: EXPO_PUBLIC_API_KEY=mex-yourname-2026
4

Save and restart Expo (npx expo start --web)
